# PeCa Viewer for Mac 0.1.0 (120)

Macのチャンネル一覧が列幅を使うよう調整し、投稿確認ボタンをコンパクトにしました。録画一覧を閉じる際に取得通信をキャンセルし、閉じた後の古い応答を適用しないよう変更しました。

ライブへの自動補正はHLSの正常状態を確認してから行い、ライブ端に近すぎる位置や短い再生範囲への自動seekを避けます。

Developer ID署名、Apple公証、Gatekeeper、DMGと更新フィードのSparkle署名を検証しました。Releaseビルドと33件の非GUIポリシー／録画モデル回帰チェックが成功しました。回帰チェックの通信には制御可能なfixtureを使用しています。

今回、署名済みアプリの起動・画面操作・実音・実IME・長時間の実配信再生は確認していません。録画一覧の実際の閉じる遅延や約267秒後の停止・復旧が解消したとは扱いません。-12640／-11867の根本原因も未確定です。

Mac版のみの配布です。iOS版や稼働中Bridgeは更新していません。録画時間上限の撤廃には対応する更新済みBridgeが必要で、容量などの保護上限は維持されます。
